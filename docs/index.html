Darkhan -- The Forge

An AI agent command center where trust is architecture, not policy. Ground truth verification, immutable audit trails, and credential isolation -- so your agents can never lie, leak, or go rogue.

Built by a founder who caught his own AI lying.

The Problem

AI agents are powerful. They are also unaccountable.

You deploy agents to automate engineering, ops, and business workflows. But when an agent fabricates a status report, leaks an API key, or acts without authorization -- you find out too late. Current tools treat trust as a prompt engineering problem. It is an architecture problem.

Agents lie

They report planned state as deployed state. They fill gaps with plausible-sounding fabrication. They say "done" when they mean "attempted." Without verification, you cannot tell the difference.

Credentials leak

Agents with access to environment variables, API keys, and database connections can exfiltrate secrets through tool calls, log output, or prompt injection attacks.

No audit trail

When something goes wrong, there is no immutable record of what happened. Logs can be modified. Claims cannot be traced to evidence. Accountability is impossible without a chain of custody.

How Darkhan is Different

Trust is enforced by architecture, not instructions.

Darkhan does not ask agents to be honest. It makes dishonesty structurally impossible to hide. Every claim is tagged. Every action is hashed. Every credential is isolated.

GT

Ground Truth Registry

Canonical verified facts stored in a registry that agents can reference but cannot modify. Claims are automatically checked against ground truth at message time -- not after the damage is done.

#

Hash Chain Audit Trail

Every message, every action, every state change is appended to a SHA-256 hash chain. Immutable, append-only, tamper-evident. If anyone modifies history, the chain breaks and you know immediately.

3L

3-Layer Credential Isolation

Layer 1: TTY+PIN break-glass (human-only recovery). Layer 2: dedicated service user with file permissions. Layer 3: macOS Keychain storage. Agents architecturally cannot access secrets.

$0

Zero-Cost Local Triage

Local LLM via Ollama handles message triage, classification, and routine responses. Cloud APIs are reserved for complex work. Operational cost for the triage layer: $0/day.

ID

Identity Enforcement

Every agent has a cryptographic identity. Messages are attributed and verified. No agent can impersonate another. Injection attempts are detected and blocked at the middleware layer.

RT

Daily Automated Red Teams

A dedicated security worker runs nightly audits: blind spot sweeps, injection scans, activity log analysis, and adversarial testing. Findings are reported before your morning standup.

How It Works

Four stages. Every message. Every time.

Darkhan routes every interaction through a verification pipeline that enforces accountability at each stage.

1

Local LLM Triage

Incoming messages hit a local model (Qwen via Ollama) for classification. Routine work is handled locally at zero cost. Complex requests are escalated to specialized workers.

2

Worker Execution

Forked worker processes run in native macOS sandboxes with restricted file access, network egress controls, and per-agent rate limits. Each worker has a defined contract and permission scope.

3

Evidence Chain

Every output is tagged with evidence references. Claims are verified against the ground truth registry. Results are hashed and appended to the immutable audit trail.

4

Human Oversight

Sensitive actions enter an approval queue. The web UI shows real-time agent health, cost tracking, and activity logs. You see what happened, why, and whether the evidence supports it.

Security Model

Security that does not depend on the agent cooperating.

Most agent frameworks secure agents with system prompts and policies. Darkhan secures agents with architecture. The agent does not need to be trustworthy -- the system verifies everything.

SHA-256 Hash Chain

Append-only activity log where each entry includes the hash of the previous entry. Tampering with any record invalidates every subsequent hash. Integrity verification is constant-time.

Ground Truth + Claim Verification

Agent messages are automatically scanned for verifiable claims. Each claim is tagged as verified, unverified, or contradicted based on the ground truth registry. No silent fabrication.

Credential Isolation

Secrets live in macOS Keychain, accessed only by a dedicated service user. The database is permission-locked. Agents run in sandboxed processes with no access to .env, secrets DB, or TLS keys.

Injection Detection

Multi-layer scanning for prompt injection in messages, tool outputs, and external content. Pattern matching, entropy analysis, and tool output sandboxing block injection vectors before they reach agents.

Pre-Commit Secret Scanner

Git hooks scan for AWS, Google, Anthropic, OpenAI, Azure, GitHub, Slack, Telegram tokens, JWTs, private keys, and connection strings. Secrets never reach the repository.

Nightly Red Team Pipeline

Automated blind spot sweep at 2330. Security plan generation at midnight. Adversarial audit at 0100. Morning brief with findings and fixes. Every night. No exceptions.

Get Started

Running in under five minutes.

Darkhan is a single deployable codebase. No Docker. No Kubernetes. Clone, configure, run. 

# Clone the repository
git clone https://github.com/outlaw4shrt/darkhan.git
cd darkhan/server

# Configure your environment
cp .env.example .env
# Edit .env with your secrets

# Install and seed
npm install
node db/seed.js

# Start the forge
node server.js
# Open http://localhost:3001

Full setup guide, worker configuration, and federation instructions are in the repository. Read the docs.
