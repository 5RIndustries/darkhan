# Privacy Policy

**Darkhan** -- an open-source AI command center by 5R Industries LLC

*Effective: March 31, 2026*

---

## The short version

Darkhan runs entirely on your machine. We do not collect your data. Period.

---

## What data we collect

None.

Darkhan is self-hosted software. When you install and run Darkhan, it operates entirely on your local machine. 5R Industries LLC has no access to your instance, your data, or your usage patterns.

Specifically, we do not collect:

- Messages or conversations
- Credentials, API keys, or passwords
- Agent configurations or outputs
- Audit logs or security events
- Usage statistics or telemetry
- IP addresses, device identifiers, or location data

There is no phone-home, no analytics, no tracking, and no telemetry of any kind.

## Where your data lives

All data generated by Darkhan stays on your machine:

- **Messages and conversations** -- stored in your local database
- **Credentials and API keys** -- stored in your local configuration
- **Agent data and outputs** -- stored in your local file system
- **Audit and security logs** -- stored locally for your review only
- **Local LLM processing** -- when using Ollama or other local models, all inference happens on your hardware

No data is transmitted to 5R Industries or any third party by Darkhan itself.

## Third-party LLM providers

Darkhan supports optional integration with external LLM providers such as Anthropic, Google, and OpenAI. If you choose to configure these integrations:

- **You** decide which providers to connect and what data to send them
- Data sent to those providers is governed by **their** privacy policies, not ours
- Darkhan does not require any external provider to function -- local LLM support is built in

We recommend reviewing the privacy policy of any external provider before configuring it.

## The darkhan.ai website

The darkhan.ai website is a static landing page. It does not use cookies, tracking pixels, analytics services, or any form of user tracking. We do not collect visitor data.

## Future telemetry

If we ever add optional telemetry or crash reporting in a future release:

- It will be **opt-in only** -- disabled by default
- We will clearly describe what is collected before you consent
- You will be able to disable it at any time
- This policy will be updated before any such feature ships

## Open source transparency

Darkhan is open source. You can inspect every line of code to verify these claims for yourself. We believe that is the strongest privacy guarantee we can offer.

## Children's privacy

Darkhan does not collect data from anyone, including children. Since no data is collected or transmitted, there is no children's data to protect. The software runs locally under the user's control.

## Changes to this policy

If we update this policy, we will note the changes in the project's release notes and update the effective date above.
