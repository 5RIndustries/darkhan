## How to Sign Off

This project uses a **Signed-off-by** process (similar to the [Developer Certificate of Origin](https://developercertificate.org/)). By adding a `Signed-off-by` line to your commit message, you certify that you agree to the terms above.

**Option 1** — Use the `-s` flag:
```
git commit -s -m "Your commit message"
```

**Option 2** — Manually add to your commit message:
```
Signed-off-by: Your Name <your.email@example.com>
```

Commits without a valid `Signed-off-by` line may not be accepted.
